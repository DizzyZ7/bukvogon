# БуквоГон

Русскоязычная соревновательная игра на скорость и точность печати.

## Идея

Игроки соревнуются в гонках, где прогресс машины напрямую зависит от корректно набранного текста. Проект строится как самостоятельная игра: собственный бренд, интерфейс, тексты, экономика, рейтинговая система и визуальный стиль.

## Модель доступа

- **Free** — обычные гонки, комнаты с друзьями, тренировка, прогресс аккаунта, гараж, достижения и базовая статистика.
- **Pro — 300 ₽/мес** — Ranked, сезонный рейтинг, официальный лидерборд, история рейтинга, расширенная соревновательная статистика и сезонные награды.
- Никаких преимуществ в скорости, точности или рейтинговых формулах за деньги: подписка открывает соревновательный контур, но не делает игрока сильнее.

## Планируемый стек

- Web: Next.js + TypeScript
- Game rendering: PixiJS / Canvas
- API: FastAPI
- Realtime: WebSocket
- Database: PostgreSQL
- Ephemeral state / matchmaking: Redis
- Tests: Pytest + Vitest/Playwright

Проект находится в активной разработке.
